Support

How to reach us, what we respond to, and how fast.

1. Support channels

  • General support: support@uapk.info — questions about the hosted API, integrations, billing, and account access.
  • Security disclosures: security@uapk.info — vulnerabilities, suspected abuse, and audit-chain integrity concerns. Please encrypt sensitive reports.
  • General inquiries: mail@uapk.info — press, partnerships, and non-technical questions.

2. Response-time commitments

We respond during European business hours (Mon–Fri, 09:00–18:00 CET/CEST), best-effort within two business days. Security reports sent to security@uapk.info are triaged within one business day.

UAPK Gateway is currently offered without a formal Service Level Agreement. Paid tiers with SLA-backed response times are on the roadmap; contact us if this is a blocker for your deployment.

3. Before you write

Most issues are faster to resolve if you include the following:

  • Your organization ID (UUID) and the approximate time of the issue (UTC)
  • The integration platform involved (Zapier, Make.com, n8n, Langflow, or direct API)
  • The endpoint or module name (e.g. POST /api/v1/gateway/execute, Make Approve Action)
  • HTTP status code and response body (redact any X-API-Key value)
  • Expected behavior vs. observed behavior

Never send your API key by email. If credential rotation is required, we will walk you through rotation in-dashboard.

4. Integration-specific help

  • Make.com: confirm your connection in Make's developer editor points to https://api.uapk.info, that the Organization ID UUID is correct, and that the health probe (GET /api/v1/orgs/{orgId}/approvals?limit=1) returns 200. See the Make.com integration guide.
  • Zapier: reconnect the authentication in Zapier if you rotated your API key. See the Zapier integration guide.
  • n8n: verify the community node version and credential configuration. See the n8n integration guide.
  • Langflow: ensure uapk-langflow is installed in the same Python environment as Langflow. See the Langflow integration guide.
